# 📚 Projeto Desenvolvimento Web – Entregas 1, 2, 3 e 4
Aluno: Carlos Eras Filho
Curso: Ciência da Computação

Este repositório contém o meu projeto desenvolvido ao longo das quatro entregas da disciplina.
Sou iniciante em programação, então organizei tudo da forma mais clara possível, sempre aprendendo enquanto fazia cada etapa.

## 🚀 Entrega 1 – HTML Semântico, Formulários e Multimídia

Nesta primeira parte, eu construí toda a estrutura HTML do projeto:

### ✔ Requisitos atendidos

• Criação de 3 páginas: index.html, projetos.html e cadastro.html

• Uso de HTML5 semântico (header, nav, main, section, article, footer)

• Formulário completo com:

  • Nome completo

  • Email

  • CPF

  • Telefone

  • Data de nascimento

  • Endereço, CEP, Cidade e Estado

•Validação HTML5 nativa

•Máscaras básicas com JavaScript

•Pastas organizadas:

css/
js/
assets/images/

## 🎨 Entrega 2 – CSS3, Design System e Layout Responsivo

Nesta fase, eu aprendi a estilizar as páginas com CSS moderno.

### ✔ Requisitos atendidos

• Criação de um Design System:

  • Paleta com 8 cores

  • Tipografia com 5 tamanhos

  • Sistema de espaçamento: 8 / 16 / 24 / 32 / 48 / 64 px

• Layout responsivo usando:

  • Grid para a estrutura maior

  • Flexbox para itens internos

  • Sistema próprio de 12 colunas

  • 5 breakpoints responsivos

• Menu principal com:

  • Submenu dropdown

  • Menu hambúrguer no mobile

• Componentes criados:

  • Cards para projetos

  • Botões com estados (hover, focus, active, disabled)

  • Formulários estilizados

  • Alerts / toasts / modais básicos

  • Tags e badges

• CSS organizado dentro da pasta:

css/
 └── style.css

## 🧩 Entrega 3 – JavaScript Avançado e SPA

Nesta parte, comecei a trabalhar com JavaScript mais avançado.

### ✔ Requisitos atendidos

• Implementação de um SPA básico

  • Área principal com id="spa-root"

  • Sistema de templates simples

• Manipulação do DOM

• Validação avançada dos formulários com mensagens ao usuário

• Criação da pasta js/ contendo arquivos separados por função

• Funções implementadas:

  • Alternância de modo alto contraste

  • Alternância de modo escuro

  • Carregamento de páginas no SPA

  • Máscaras para CPF, telefone e CEP

Arquivo:

js/scripts.js

## ♿ Entrega 4 – Acessibilidade, Versionamento e Deploy

Nesta etapa final, aprendi sobre Git e boas práticas profissionais.

### ✔ Requisitos atendidos
### Git/GitHub

• Uso do GitFlow com branches:

  • main

  • develop

  • branches de features

• Commits semânticos

• Pull Requests e Issues organizadas

• Repositório público

### Acessibilidade WCAG 2.1 AA

• Navegação total por teclado

• Contraste acima de 4.5:1

• Estrutura totalmente semântica

• Suporte para leitores de tela (aria-label, role, etc.)

• Implementado:

  • Modo de Alto Contraste

  • Modo Escuro Acessível

### Otimização

  • Imagens otimizadas

  • CSS, JS e HTML minificados

  • Preparação para deploy
